# kundanvishen.com

Personal site. Plain Jekyll, no theme, no JS. Deployed by GitHub Pages from the `gh-pages` branch.

## Update "Now"

Edit `now.md`, change the "Updated" line, commit, push. Done.

## Add a post

Create `_posts/YYYY-MM-DD-slug.md`:

```
---
title: The title
---
Body in markdown.
```

Push. It appears at `/writing/slug/` and on the Writing index.

## Run locally (optional)

```
bundle install
bundle exec jekyll serve
```
